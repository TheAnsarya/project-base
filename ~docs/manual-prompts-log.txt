------------------------------------------------------------------

create folders: `/~docs/` for information about the creation of the repos/project, `/docs/` for information about the project itself, add summary logs and chat logs in the `~docs` folder as markdown files;

comment and document everything; maintain chat logs like `2025-12-25-chat-01.md` in the `~docs\chat-logs` folder, and session summaries like `2025-12-25-session-01.md` in the `~docs\session-logs` folder, see the `GameInfo` repos for inspiration;

make new feature branches for each big work effort and merge them back down the chain when they are done;
